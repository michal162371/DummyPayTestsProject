## Priority guide (suggested; confirm with instructor)
- P0: blocks a critical core journey.
- P1: important functionality, but not blocking the entire product.
- P2: less-critical functionality or presentation.

## Suite guide
- Smoke: small set of verified P0 journeys.
- Regression: broader set of P0/P1/P2 scenarios.
- Nightly: potentially lengthy or full regression coverage.

## Discovery checklist
Record the actual URLs, page titles, buttons, validation messages, workflows and test-data requirements before authoring cases.
